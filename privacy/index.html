개인정보처리방침

NoveraFlow는 사용자의 기록을 소중하게 다룹니다. 사용자를 추적하거나 광고 목적으로 데이터를 판매하지 않으며, 기록 데이터는 기록 경험과 AI 피드백 제공을 위해 필요한 범위에서만 사용합니다.

시행일 및 최종 업데이트: 2026년 6월 16일

1. 수집하는 정보

NoveraFlow는 서비스 제공을 위해 다음 정보를 처리할 수 있습니다.

  • 사용자가 작성한 기록 내용
  • 사용자가 선택한 상징, 상태, 키워드
  • 사용자가 직접 첨부한 사진 파일
  • 사용자가 직접 첨부한 음성 파일
  • 앱 사용 이벤트, 예를 들어 기록 생성, 기능 사용, 오류 확인에 필요한 이벤트
  • 피드백 평가 데이터, 예를 들어 도움됨, 보통, 아쉬움 선택과 피드백 유형 정보

NoveraFlow는 광고 식별자를 이용해 사용자를 추적하거나 광고 프로파일을 만들기 위해 기록 데이터를 수집하지 않습니다.

2. 수집 및 이용 목적

수집 또는 처리되는 정보는 다음 목적을 위해 사용됩니다.

  • 사용자의 기록 저장 및 표시
  • 기록에 기반한 AI 피드백 생성
  • 반복되는 감정, 상징, 흐름, 패턴 분석
  • 앱 안정성 확인 및 서비스 개선
  • 피드백 평가를 통한 피드백 품질 개선

AI 피드백은 사용자의 기록을 판단하거나 진단하기 위한 기능이 아니며, 기록을 돌아볼 수 있도록 돕는 참고용 반응입니다.

3. 데이터 보관 및 저장 위치

현재 v1 정책에서 기본 기록 데이터는 사용자의 기기에 로컬로 저장됩니다. 사용자가 작성한 기록, 선택한 상징, 사진 첨부 파일, 음성 첨부 파일은 기본적으로 사용자의 기기 안에서 기록 경험을 제공하기 위해 보관됩니다.

사용자는 앱에서 직접 백업 파일을 생성할 수 있습니다. 백업 파일은 사용자가 저장하거나 이동한 위치에 보관되며, 해당 파일의 관리와 삭제는 사용자가 직접 수행합니다.

앱 사용 이벤트와 피드백 평가는 서비스 안정성 확인, 운영 통계, 피드백 품질 개선을 위해 서버로 전송되어 보관될 수 있습니다. 이 경우 개인을 직접 식별하는 정보는 최소화하여 처리합니다.

향후 클라우드 동기화, 계정, 서버 기반 백업 기능이 추가되는 경우 실제 데이터 흐름에 맞추어 본 방침을 갱신하고 필요한 경우 앱 안에서 추가 안내를 제공합니다.

4. 제3자 제공 및 판매 금지

NoveraFlow는 사용자의 개인정보나 기록 데이터를 판매하지 않습니다. 또한 광고 목적으로 사용자의 기록 데이터, 첨부 파일, 피드백 평가 데이터를 제3자에게 제공하지 않습니다.

서비스 운영에 필요한 호스팅, 보안, 오류 분석, AI 처리 등 기술 제공자가 사용될 수 있는 경우에도 해당 처리는 서비스 제공과 개선에 필요한 범위로 제한됩니다. 법령에 따른 요청이 있거나 사용자의 명시적 요청이 있는 경우를 제외하고, 사용자의 기록을 임의로 공개하지 않습니다.

5. 사용자 권리와 삭제

사용자는 앱 안에서 자신의 기록을 삭제할 수 있습니다. 앱을 삭제하면 기기에 로컬로 저장된 앱 데이터가 함께 삭제될 수 있습니다. 다만 사용자가 별도로 생성하여 외부 위치에 저장한 백업 파일은 사용자가 직접 삭제해야 합니다.

개인정보 처리와 관련한 문의, 삭제 요청, 정책 문의는 아래 연락처로 보낼 수 있습니다. 요청을 받으면 서비스 운영 상태와 법적 의무에 따라 합리적인 범위에서 처리합니다.

6. 보안

NoveraFlow는 사용자의 기록과 관련 데이터를 보호하기 위해 합리적인 수준의 기술적, 관리적 보호 조치를 적용합니다. 다만 인터넷, 기기, 운영체제, 백업 파일 관리 환경의 특성상 어떠한 방식도 완전한 보안을 보장할 수는 없습니다.

7. 아동의 개인정보

NoveraFlow는 아동을 대상으로 개인정보를 의도적으로 수집하도록 설계된 서비스가 아닙니다. 관련 법령상 보호가 필요한 이용자의 데이터 처리에 별도 동의나 보호 조치가 필요한 경우, 해당 요건을 충족하기 전까지 기능 제공이 제한될 수 있습니다.

8. 정책 변경

서비스 기능, 데이터 처리 방식, 법령 또는 플랫폼 정책이 변경되면 본 개인정보처리방침이 수정될 수 있습니다. 중요한 변경이 있는 경우 웹사이트 또는 앱 내 공지 등 적절한 방법으로 안내합니다.

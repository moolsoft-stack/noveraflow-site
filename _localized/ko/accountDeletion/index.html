NoveraFlow AI 기록 계정 삭제

NoveraFlow(moolsoft)는 삭제 요청을 마케팅, 광고 또는 다른 동의에 연결하지 않습니다.

시행일 및 최종 업데이트: 2026년 9월 2일

앱에서 삭제하는 경로

  1. 로그인 후 홈의 계정/설정 아이콘을 엽니다.
  2. 계정 → 계정 삭제를 선택합니다.
  3. Google 또는 Apple로 다시 인증하고 최종 확인합니다.

Apple 로그인 계정은 가능한 경우 Apple 토큰 철회를 먼저 시도합니다. 철회 가능한 자격 증명을 받을 수 없더라도 검증된 계정 삭제는 완료되며, 앱이 Apple 설정에서 수동으로 연결을 해제하는 방법을 안내합니다. Google 로그인 계정에는 이 Apple 단계가 적용되지 않습니다.

로그아웃은 계정을 삭제하지 않습니다. 삭제가 완료되면 복구할 수 없습니다.

앱을 사용할 수 없을 때

계정 삭제 전용 제목으로 이메일 보내기

제목은 NoveraFlow Account Deletion Request로 유지하고, 본문에는 로그인 제공자(Google/Apple)와 회신 가능한 계정 이메일만 적어 주세요. Apple의 나의 이메일 가리기를 사용했다면 Apple 설정에 표시되는 중계 이메일을 적어 주세요. UUID, 비밀번호, 인증 코드, 토큰, 기록 또는 문의 본문은 보내지 마세요.

운영자는 계정에 연결된 이메일로 일회용 본인 확인 절차를 안내합니다. 본인 확인이 끝난 요청만 계정 삭제로 처리하며, 확인에 실패하면 삭제하지 않습니다.

삭제 및 보유 범위

  • Supabase Auth 로그인 계정: 서버 정리와 필요한 로그인 제공자 처리 후 영구 삭제
  • 계정 UUID 연결과 Support 알림 outbox: 즉시 제거
  • 계정 삭제 관련 문의 내용: 즉시 일반 조회 차단, 최대 7일 안에 물리 삭제
  • 계정 소유 Push receipt, device, 암호화 token: 즉시 제거. 보존되는 Push dispatch 감사 JSON에서는 일치하는 수신 계정 UUID 필드만 즉시 제거하며 다른 사용자의 dispatch는 변경하지 않음
  • Support rate-limit hash: 마지막 사용 후 최대 24시간
  • 비활성 열린 문의: 마지막 활동 90일 후 자동 종료
  • 일반 종료 문의 내용: 종료 후 180일
  • 백업: 최대 30일; 복구 시 deletion replay를 다시 적용
  • keyed-HMAC replay ledger: 최대 31일
  • 계정 UUID·이메일·본문이 없는 최소 tombstone/audit와 deletion receipt: 최대 365일
  • 기기 생성 익명 analytics 식별자: 로그인 계정 UUID와 분리되어 있어 계정 삭제에 자동으로 연결되거나 삭제되지 않음. 앱 데이터 삭제 시 로컬 사본은 삭제되지만, 서버가 이미 수신한 계정 비연결 analytics 이벤트는 계정 삭제로 삭제되지 않음

로그인 계정 UUID와 분리된 익명 analytics 이벤트 및 AI 피드백 quota/usage 항목과, 수신 계정 UUID를 제거한 Push dispatch 감사 필드에는 현재 자동 기간 만료가 구현되어 있지 않아 고정된 보유기간이 없습니다. 이 항목들은 Supabase 계정 삭제에 자동 연결되지 않습니다.

기기 기록

휴대전화의 로컬 기록은 기본적으로 유지됩니다. 삭제 화면에서 이 기기의 기록도 함께 삭제를 별도로 선택한 경우에만, 서버 삭제 완료 후 앱 관리 기록과 첨부파일을 삭제합니다. 직접 내보낸 백업 ZIP은 앱이 관리하지 않으므로 직접 삭제해야 합니다.

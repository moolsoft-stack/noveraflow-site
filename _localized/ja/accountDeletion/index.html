アカウント削除

NoveraFlow AI記録のアカウント削除

moolsoftが運営するNoveraFlowは、削除リクエストをマーケティング、広告、その他の同意に結び付けません。

施行日および最終更新日：2026年9月2日

アプリ内で削除する手順

  1. ログイン後、ホームからアカウント／設定アイコンを開きます。
  2. アカウント → アカウントを削除を選びます。
  3. GoogleまたはAppleで再認証し、最終確認を行います。

Appleログインのアカウントでは、利用可能な認証情報がある場合、Appleトークンの取り消しを先に試みます。取り消し可能な認証情報を取得できなくても、確認済みのアカウント削除は完了し、Apple設定で連携を手動解除する方法をアプリで案内します。このApple手順はGoogleログインのアカウントには適用されません。

ログアウトではアカウントは削除されません。完了した削除は元に戻せません。

アプリを利用できない場合

削除専用件名でメールを送る

件名は NoveraFlow Account Deletion Request のままにし、ログインプロバイダー（Google/Apple）と返信可能なアカウントメールだけを記載してください。Appleの「メールを非公開」を利用している場合は、Apple設定に表示される転送用アドレスを記載してください。UUID、パスワード、認証コード、トークン、記録、問い合わせ本文は送らないでください。

運営者はアカウントに紐づくメールへ1回限りの本人確認手順を案内します。確認済みのリクエストだけをアカウント削除として処理し、確認できない場合は削除しません。

削除・保持期間

  • Supabase Authログインアカウント：サーバーの整理と必要なログインプロバイダー処理後に完全削除
  • アカウントUUIDの紐付けとSupport通知outbox：直ちに削除
  • アカウント削除に伴う問い合わせ内容：直ちに通常閲覧を停止し、最長7日以内に物理削除
  • アカウント所有のPush receipt、device、暗号化token：直ちに削除。保持されるPush dispatch監査JSONから一致する受信アカウントUUIDフィールドだけを直ちに削除し、他の利用者のdispatchは変更しない
  • Support rate-limit hash：最終利用から最長24時間
  • 非アクティブな未終了問い合わせ：90日後に自動終了
  • 通常終了した問い合わせ内容：終了後180日
  • バックアップ：最長30日、復元後にdeletion replayを再適用
  • keyed-HMAC replay ledger：最長31日
  • アカウントUUID・メール・本文を含まない最小tombstone/auditとdeletion receipt：最長365日
  • 端末で生成される匿名analytics識別子：ログインアカウントUUIDとは別で、アカウント削除に自動で紐付けまたは削除されない。アプリデータを消去すると端末内のコピーは削除されるが、サーバーが受信済みのアカウント非連携analyticsイベントはアカウント削除では削除されない

ログインアカウントUUIDとは別の匿名analyticsイベントおよびAIフィードバックquota/usage項目と、受信アカウントUUID削除後に残るPush dispatch監査フィールドには、現在、自動的な期間満了が実装されておらず、固定の保持期間はありません。これらはSupabaseアカウント削除に自動で紐付きません。

端末内の記録

端末内の記録は初期設定では保持されます。この端末の記録も削除するを別途選んだ場合に限り、サーバー完了後にアプリ管理の記録と添付ファイルを削除します。書き出したバックアップZIPはご自身で削除してください。

処理状態と連絡先

アプリには再認証、最終確認、リクエスト中、処理中、完了、安全な再試行が表示されます。連絡先：moolsoft+help@gmail.com
